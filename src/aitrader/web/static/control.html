Монеты и их стратегии

На каждой монете торгует лучшая на ней стратегия из прошедших проверки на истории (прибыль на этой монете с поправкой на просадку), у каждой монеты своя. Набор заморожен на весь эксперимент: по каждой монете копится чистая статистика. «Выбрать» — поставить на монету любые стратегии из списка лучших для неё. Сортировка — по клику на заголовок любой колонки, во всех таблицах.
