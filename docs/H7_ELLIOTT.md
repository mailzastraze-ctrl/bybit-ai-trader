## 1. Вопрос
Добавляет ли волновая разметка преимущество к обычным свинговым сигналам? Сначала W3 и W5 проверяются как самостоятельные сигналы. Фильтры для существующих стратегий — отдельная гипотеза H7b, только после H7.

## 2. Данные
- Вселенная, ликвидность на дату сигнала, делистинги (иначе пометка `survivorship`), период 23.11.2023–23.11.2026, разбиение и издержки (≈ 21 bp за круг + фандинг) — как в H6 §3.
- Корреляция и перекрытие учитываются через N_eff (H6 §5) и правило `dependent` (H6 §4.7).
- BTC/ETH/SOL — заявленный срез: отдельно в отчёте, в семейство первичных проверок не входит.
- Кандидаты в таймфреймы: 15m, 1h, 4h. Какие допускаются, решает шаг 0.

## 3. Пивоты и степень волны
- Пивоты по H6 §4.2: k = 3 на 4h, k = 5 на 1h и 15m.
- Степень волны определяется объективно: каждое плечо ≥ 1·ATR(14) своего ТФ на конце плеча. Последовательность с более коротким плечом не размечается как волна. Пивоты не сливаются, перерисовки нет.
- Контекст 4h для 1h и 15m — признак структуры свингов из H6 §4.6. Используется в одном заранее заявленном разрезе, не как фильтр.

## 4. W3 (long; short — зеркало)
- Волновой сигнал W3 — это аналоговый сигнал W3 (§7), для которого дополнительно выполнены правила ниже. Опорные точки те же, что у аналога:
  - S0 — подтверждённый swing low непосредственно перед P1; для волны он ещё и минимальный low за 50 свечей до себя;
  - P1 — следующий swing high;
  - P2 — следующий swing low.
- Проверяется только то, что известно к подтверждению P2:
  - P2 > S0;
  - откат (P1 − P2)/(P1 − S0) ∈ [0,382; 0,786];
  - каждое плечо ≥ 1·ATR.
- Сигнал — первая свеча из P2+k … P2+k+20 с close ≥ P1 + 0,25·ATR. Отмена — если раньше было close < P2.
- Стоп — P2 − 0,25·ATR. Цель — P2 + 1,618·(P1 − S0). Выход по времени — через 24 свечи.

## 5. W5 (short после бычьего импульса; long — зеркало)
- Волновой сигнал W5 — это аналоговый сигнал W5 (§7), для которого дополнительно выполнены правила ниже. S0 — swing low непосредственно перед P1; для волны он ещё и минимальный low за 50 свечей до себя. P1 … P5 — чередующиеся подтверждённые пивоты.
- Правила импульса:
  - P2 > S0;
  - волна 3 не самая короткая из волн 1, 3, 5;
  - P4 > P1;
  - P5 > P3 (P1 < P3 < P5 уже требует аналог);
  - каждое плечо ≥ 1·ATR.
- Сигнал — первая свеча из P5+k … P5+k+20 с close ≤ P4 − 0,25·ATR. Отмена — если раньше было close > P5 + 0,25·ATR.
- Стоп — P5 + 0,25·ATR. Цель — P5 − 0,382·(P5 − S0). Выход по времени — через 24 свечи.

## 6. Исполнение
- Сигнал — на закрытии свечи, вход — по открытию следующей (H6 §4.1). R = |вход − стоп| по фактической цене входа.
- **Исполнимость** проверяется по фактическому входу до исхода сделки. Long: стоп < вход, и цель ≥ вход + полный круг издержек. Short — зеркально.
  - Стоп не на стороне убытка — статус `bad_stop`.
  - Цель не дальше полного круга издержек в сторону прибыли — статус `no_room`. Без этого правила цель W5 может оказаться на убыточной стороне. Пример: 0 → 10 → 5 → 25 → 12 → 26, цель 16,1 при входе 12.
  - Такие сигналы не торгуются. Доли `bad_stop` и `no_room` показываются по каждой гипотезе, ТФ и группе (волновые, остальные аналоговые, плацебо). Разница долей между группами входит в отчёт: от неё зависит, что именно сравнивает Δ.
- **Модель исполнения.** Предела убытка −1R по допущению нет.
  - Стоп исполняется по цене стопа. Если свеча открылась за стопом — по её открытию, и убыток больше 1R.
  - Цель исполняется по цене цели, а если свеча открылась за целью — по открытию.
  - Если на одной свече задеты и стоп, и цель, считается стоп.
  - Сверху 5 bp на сторону, комиссии и фандинг.
- Одна позиция на монету и ТФ, приоритет у более раннего сигнала.

## 7. Аналоги и эталоны
- У аналогов те же окно сигнала, порог пробоя, отмена, вход, стоп, формула цели, выход по времени, проверка исполнимости (§6) и издержки:
  - **аналог W3** — три подряд подтверждённых пивота S0 (swing low), P1 (swing high), P2 (swing low) с P2 > S0. Сигнал — пробой P1 по правилам §4. Без условия минимума за 50 свечей, без полосы отката, без условия на длину плеч;
  - **аналог W5** — шесть подряд чередующихся пивотов S0, P1 … P5 с P1 < P3 < P5 (три растущих swing high). Сигнал — пробой P4 по правилам §5. Без остальных правил Эллиотта.
  - В обоих аналогах S0 — swing low непосредственно перед P1. Поэтому формула цели определена для каждого аналогового сигнала.
- Волновая метка — признак аналогового сигнала: подмножество получается по построению. У волнового сигнала и его аналоговой версии одинаковы S0, вход, стоп, цель и сделка. Волновой кандидат, который не является аналоговым сигналом, — ошибка детектора, на это есть тест.
- Основное сравнение — волновое подмножество против остальных аналоговых сигналов того же ТФ.
- Ещё два эталона:
  - TSMOM `benchmark-tsmom-4h-30d` при равном риске;
  - случайные входы (плацебо): та же монета, тот же блок дат, то же направление.

## 8. Шаг 0 — без доходностей после сигналов
- Что считается:
  - число волновых и аналоговых сигналов по ТФ, доли `bad_stop` и `no_room` по группам;
  - распределение структурных стопов в % цены и в ATR;
  - издержки в R;
  - перекрытие и кластеризация сигналов по датам;
  - σ групп по плацебо (§9). Записывается только σ; среднее плацебо до шага A не показывается.
- До шага A по этим числам заполняется заранее заданное правило допуска ТФ: медиана издержек ≤ 0,1R **и** MDE_Δ ≤ 0,1R (§9). При 21 bp за круг первое условие означает стоп около 2,1 % цены.
- Отдельные сигналы по издержкам не выбрасываются: издержки и так целиком вычитаются в R.
- Недопущенный ТФ остаётся только описательным и в семейство проверок не входит.

## 9. Мощность (сравнение двух групп)
- Первичная проверка односторонняя (Δ > 0), поэтому MDE_Δ = (z_{1−α/m} + z_{0,8})·SE_Δ. Порог взят по первому, самому строгому шагу Holm.
- SE_Δ ≤ σ_w/√N_eff,w + σ_o/√N_eff,o, где w — волновые сигналы, o — остальные аналоговые. Граница верна при любой корреляции между группами: сигналы одних монет и дат зависимы. Поэтому корреляцию не нужно оценивать по исходам. Это консервативная оценка, корректная при правильно оценённых σ и N_eff.
- N_eff,w и N_eff,o — для каждой группы отдельно, через design effect (H6 §5) с кластерами по дате и монете.
- σ_g — стандартное отклонение чистого R плацебо-сделок с геометрией сигналов группы g:
  - для каждого сигнала берутся K = 20 случайных входов: та же монета, тот же блок дат, та же сторона;
  - у них те же расстояния до стопа и цели в ATR, тот же выход по времени, та же модель исполнения (§6) и те же издержки.
  - Так σ учитывает гэпы и проскальзывание.
- **σ не зависит от исходов сигналов** (уточнение ChatGPT, 23.11):
  - используется только то, что известно на входе сигнала (монета, дата, сторона, расстояния до стопа и цели), и цены в случайные моменты;
  - случайный вход не попадает в окно удержания самого сигнала: от его входа до выхода по времени (24 свечи);
  - K, правило выбора случайных входов и сид генератора зафиксированы здесь;
  - σ считается один раз на шаге 0 и после шага A не пересчитывается и не подбирается.
- Ориентир: SE_Δ ≤ 0,031R. При σ ≈ 1–2R это требует N_eff волновой группы порядка 1 000–4 000. Если данных мало, фиксируется «недостаточно данных». Пороги не снижаются.

## 10. Метрика и проверки
- Метрика — средний чистый R на сделку: после комиссий, 5 bp на сторону и фандинга. Считается только по сделкам, прошедшим проверку исполнимости (§6).
- Первичная проверка: Δ = средний R волновых сигналов минус средний R остальных аналоговых. Считается для каждой гипотезы (W3, W5) и каждого допущенного ТФ, m ≤ 6. Поправка Holm, α = 0,05, проверка односторонняя: нужно Δ > 0.
- Направления объединены через зеркало, по отдельности — диагностика.
- Вторичные проверки:
  - средний чистый R волновых сигналов > 0 и выше плацебо;
  - сравнение с эталоном TSMOM.
- Вывод — календарный блочный bootstrap, как в H6 §6.3.
